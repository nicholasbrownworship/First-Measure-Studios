# /media

Drop self-hosted episode audio/video files here (referenced by `mediaUrl` in the `EPISODES` array in `show.html`).

For most video, YouTube is the better option — free hosting/streaming/bandwidth, no repo bloat. Reserve this folder for audio files or short clips where a full YouTube upload isn't worth it.

Keep individual files well under 100MB (GitHub's hard per-file limit) and be mindful of total repo size over time.

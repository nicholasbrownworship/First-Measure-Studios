Session Recorder

A lightweight backup recorder that runs entirely in this browser tab — useful as a fallback if the main recording rig has trouble. Nothing is uploaded anywhere; the file stays on this device until you download it.

How this works: everything happens locally in your browser using the Web Audio/MediaRecorder APIs. No server, no account, no upload — when you stop recording, you get a downloadable file and that's it. Closing this tab without downloading discards the recording, so download before you navigate away.
